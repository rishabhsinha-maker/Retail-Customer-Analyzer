# PROJECT REPORT

# RETAIL CUSTOMER ANALYZER

## 1. Introduction

Retail Customer Analyzer is a Python-based data analytics project.

It analyzes customer purchasing information and helps understand customer spending patterns.

## 2. Problem Statement

Retail businesses generate customer data regularly.

Analyzing this data manually is difficult.

This project uses Python to analyze customer information and generate useful insights.

## 3. Objectives

1. Analyze customer information.
2. Calculate total sales.
3. Find average customer spending.
4. Identify the highest spending customer.
5. Perform city-wise sales analysis.
6. Generate a spending chart.

## 4. Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## 5. Methodology

Step 1: Create customer dataset.

Step 2: Convert data into a Pandas DataFrame.

Step 3: Calculate total sales and average spending.

Step 4: Identify the highest spending customer.

Step 5: Perform city-wise sales analysis.

Step 6: Sort customers according to spending.

Step 7: Generate a bar chart using Matplotlib.

## 7. Conclusion

The Retail Customer Analyzer successfully analyzes customer purchasing data.

It provides useful information about customer spending, purchases, and city-wise sales.

This project demonstrates the practical use of Python, Pandas, and Matplotlib in data analytics.
