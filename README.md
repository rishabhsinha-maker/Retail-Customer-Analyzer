🛍️ Retail Customer Analyzer

Python-Based Customer Data Analysis Project

---

📌 Project Overview

Retail Customer Analyzer is a Python-based data analysis project developed to analyze customer purchasing behavior using Pandas and Matplotlib.

The project analyzes customer spending patterns, purchase frequency, revenue, and city-wise sales performance.

It helps understand retail business performance through data analysis and visualization.

🎯 Project Objectives

- Analyze customer purchasing behavior.
- Calculate total customer purchases.
- Calculate total revenue.
- Find average customer spending.
- Identify the highest spending customer.
- Perform city-wise sales analysis.
- Visualize customer spending through charts.
